<h1 align="center">oshi</h1>

<p align="center">minimal text editor that does its work...</p>

```sh
make
make install          # ~/.local/bin/oshi
sudo make install     # /usr/local/bin/oshi
```

```sh
oshi file.txt         # edit a file
oshi folder/          # file browser
```

`ctrl-?` for help

Config lives in `~/.config/oshi/config`.
